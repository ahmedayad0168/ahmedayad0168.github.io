Selected projects

FlowCraft-DiT

PyTorch · Rectified Flow · MM-DiT · CLIP

An experimental text-to-image model trained from scratch with Rectified Flow Matching and a Multimodal Diffusion Transformer (AdaLN-Zero, 2D RoPE, CLIP conditioning, latent images, mixed precision, ODE sampling). The documented 10.1M-parameter setup generates 128×128 images in about 1.2 s (28 ODE steps) with roughly 4.2 GB of VRAM. It is a research implementation, limited by training progress, dataset size and capacity.

Omni-AgriVision

YOLO11 · ByteTrack · EfficientNet · DeepLabV3+ · FastAPI · Redis · Celery

An agricultural decision-support platform: drone video goes through detection and tracking, then disease classification and lesion segmentation, feeding field analytics and a RAG/agent assistant. Documented evaluations: YOLO11m 89.0% mAP50 (76.8% mAP50–95); EfficientNet-B0 99.58% validation accuracy on 38 classes. These are benchmark results, not guaranteed field performance.

Multi-Agent Research System

FAISS · Sentence Transformers · Tavily · RAGAS · Ollama · Gradio

Specialized agents coordinate instead of answering in one shot: local-document retrieval first, web search when evidence is weak, a critic that checks faithfulness with RAGAS, and persistent memory. Includes a Gradio UI with microphone input.

DiffusionCraft

PyTorch · VAE · CLIP · cross-attention U-Net · DDIM · FastAPI · Chainlit

A latent diffusion pipeline built to learn the fundamentals end to end, served through FastAPI and a Chainlit chat UI. Unlike FlowCraft-DiT, it uses a convolutional U-Net with noise-prediction diffusion rather than a transformer trained with flow matching. Output quality is compute-limited.

Hybrid RAG + Text-to-SQL Assistant

FAISS · BGE embeddings · fine-tuned T5 · SQL Server · Ollama

A local assistant that routes each question to PDF retrieval, to SQL (generated by a fine-tuned T5-style model, then validated before execution), or to both, with Ollama writing the answer.
