Selected projects

FlowCraft-DiT

PyTorch · Rectified Flow · MM-DiT · CLIP

An experimental text-to-image model trained from scratch with Rectified Flow Matching and a Multimodal Diffusion Transformer. It uses AdaLN-Zero, 2D rotary position embeddings, CLIP text conditioning, latent image representations, mixed-precision training, and ODE-based sampling. The documented 10.1M-parameter configuration generates 128×128 images in roughly 1.2 s each (28 ODE steps) using about 4.2 GB of VRAM. It is a research implementation: the repository itself notes limits from training progress, dataset size, and model capacity, so it is not a state-of-the-art generator.

Omni-AgriVision

YOLO11 · ByteTrack · EfficientNet · DeepLabV3+ · FastAPI · SQL Server · Redis · Celery

An agricultural decision-support platform that connects computer vision with AI assistance. Drone video goes through object detection and multi-object tracking, then disease classification and lesion segmentation, feeding field analytics and a retrieval/agent layer for questions. Reported evaluation results from the repository: YOLO11m reaches 89.0% mAP50 (76.8% mAP50–95), and EfficientNet-B0 reaches 99.58% validation accuracy over 38 classes. These are documented evaluation numbers, not guaranteed field performance.

Multi-Agent Research System

Python · FAISS · Sentence Transformers · Tavily · RAGAS · Ollama · Gradio

A research assistant that coordinates specialized agents instead of producing one isolated answer. Questions are first tried against local documents (FAISS retrieval); if the local evidence is weak, a search agent collects web evidence. A critic agent checks faithfulness with RAGAS, and a persistent memory (JSON plus a FAISS index) carries context forward. It has a Gradio interface with microphone input.

DiffusionCraft

PyTorch · VAE · CLIP ViT-B/32 · cross-attention U-Net · DDIM · FastAPI · Chainlit

A text-to-image latent diffusion pipeline built to learn the fundamentals end to end: a 3.71M-parameter VAE, frozen CLIP text conditioning, a conditional U-Net with cross-attention, and DDIM sampling, served through a FastAPI backend and a Chainlit chat interface. It differs from FlowCraft-DiT in architecture and objective: a convolutional U-Net with noise-prediction diffusion here, versus a transformer trained with flow matching there. The README is explicit that output quality is limited by compute, not code.

Hybrid RAG + Text-to-SQL Assistant

FAISS · BGE embeddings · fine-tuned T5 · SQL Server · Ollama (llama3)

A local assistant that answers from both PDFs and a SQL Server database. A router sends each question down a document path (FAISS retrieval with bge-small-en-v1.5), a SQL path (a fine-tuned T5-style model generates SQL, which is cleaned and validated to block dangerous statements before execution), or both, and Ollama writes the final answer.

More: Medical Support Assistant (Chainlit + Ollama symptom extraction over an SQL Server knowledge base) and Medical Diagnosis Project. Both are educational and experimental, not intended for clinical use.
